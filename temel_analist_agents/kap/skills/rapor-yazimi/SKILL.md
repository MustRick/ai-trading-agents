# Skill: KAP Analiz Raporu

## Amaç
Tüm KAP skill çıktılarını `templates/kap_rapor.md` şablonuna göre birleştir.

## Adımlar
1. Tüm skill çıktılarını topla (bildirim-filtreleme, radar, faaliyet-raporu-ozeti, takvim)
2. Şablonu doldur
3. `reports/YYYYMMDD_HISSE_kap.md` olarak kaydet
4. `memory/uyarilar.md` güncelle — açık uyarı varsa ekle

## Dosya Şeması
`reports/20261012_THYAO_kap.md`
