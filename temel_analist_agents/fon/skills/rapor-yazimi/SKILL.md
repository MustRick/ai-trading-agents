# Skill: Fon Analiz Raporu

## Amaç
Tüm fon skill çıktılarını `templates/fon_rapor.md` şablonuna göre birleştir.

## Adımlar
1. Tüm skill çıktılarını topla (getiri, risk-getiri, portföy, akış, bes)
2. Şablonu doldur
3. `reports/YYYYMMDD_FON_analiz.md` olarak kaydet
4. `memory/karsilastirma_log.md` güncelle

## Dosya Şeması
`reports/20261012_AK_portfoy_fon_analiz.md`
