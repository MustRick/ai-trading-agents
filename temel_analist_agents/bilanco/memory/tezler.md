# Yatırım Tezleri

Aktif ve arşivlenmiş tezler. Tez = neden bu hissede değer olduğuna dair yapısal argüman.

## Şema
```
### XXXXX — Kısa Tez Başlığı
- **Durum:** Aktif / Teyit Bekliyor / Çürütüldü / Gerçekleşti
- **Tez:** [2-3 cümle. Neden değerli, hangi katalizör, hangi risk]
- **Doğrulama Kriteri:** [Tezin doğru olduğunu neyle anlayacağız?]
- **Çürütme Kriteri:** [Tezin yanlış olduğunu neyle anlayacağız?]
- **Tarih:** YYYY-MM-DD
- **Son Güncelleme:** YYYY-MM-DD
```
